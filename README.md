# CT_IMAGE_NOISE_REMOVER
A publication-quality, modular, research-oriented Intelligent Medical CT Restoration Framework for adaptive noise characterization, expert-based denoising, fusion, evaluation and explainable medical image restoration. Built with Python 3.13 using a layered architecture designed for extensibility, reproducibility and future clinical research.

# Intelligent Medical CT Restoration Framework

A publication-quality research framework for adaptive CT image restoration.

## Features

- DICOM-based medical image pipeline
- HU conversion
- CT windowing
- Adaptive normalization
- Noise characterization
- Intelligent routing
- Expert-based restoration
- Fusion engine
- Evaluation framework
- Explainability (GradCAM / SHAP)
- Modular architecture
- Research-grade implementation
- Python 3.13

Project follows a strict, layered development strategy where every layer is independently implemented, reviewed, tested, locked and versioned.
